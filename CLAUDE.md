# Final Exam - Visual Computing 2026-I

## Project Context

This repository contains the final practical exam for the Visual Computing course at Universidad Nacional de Colombia.

The repository has two exercises:

1. Image Processing and Computer Vision (Python + OpenCV)
2. Interactive 3D Scene (Three.js)

## Exercise 1

Requirements:
- Load image or video
- Convert to grayscale
- Convert to HSV
- Apply Gaussian Blur
- Apply Canny edge detection
- Perform object detection using YOLOv8
- Save all intermediate outputs

Output folder:
ejercicio_1_procesamiento_visual/resultados/

## Exercise 2
